# FIGHTROOM — MMA Content Marketplace MVP
A Persian RTL content marketplace concept for ELOHIM MMA.

## Product structure
- Shorts: ready-to-publish short-form content packages
- Fighter Files: biography, stats, career timeline and source links
- Story Lab: editorial categories
- Collections: Free / Short Pack / Fighter Pack / Event Pack
- Official Watch: legal official watch links
- Rights-first: content is referenced/embedded unless hosting rights are explicitly recorded

## Current demo
The homepage uses Rodtang Jitmuangnon and Takeru Segawa as the first real content example, based on official ONE Championship material.
