- Source: https://www.innerscene.com/tools/library/3d-parts/female-base-mesh-3d-person-rigged-a-pose-dba97ed5
- Licence: CC0 public-domain dedication, as stated on the source page.
- Publisher describes a 163-bone rig with skin weights.
- Source asset: `female-base-mesh-base_female.glb` (4,497,424 bytes).
- SHA-256: `7E45EF5EF58D4E6A3AA17EF4078CB5FFB02C3964CEF67C393973A6D4C0A8CBF8`.
- This is a neutral base mesh, not a finished clothed fighter. FIGHTROOM loads it only with its original runtime fightwear overlay (sports top, shorts, hair, gloves and shoes); the overlay is created by `mocap-runtime.js`.
- The eight bundled ACCAD clips are retargeted to this rig. Paired CMU motion can also be retargeted to this model as one actor in a synchronized two-fighter preview.
- Visual clipping, art polish and physical Android performance QA are still required before release.
