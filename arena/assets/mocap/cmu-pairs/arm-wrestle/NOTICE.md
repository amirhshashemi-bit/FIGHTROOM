# CMU paired motion capture — arm-wrestling interaction

- Original source: Carnegie Mellon University Graphics Lab Motion Capture Database
- Official motion index: https://mocap.cs.cmu.edu/search.php?maincat=1&subcat=1
- Trial: Subject 22 / Trial 17 (Actor A) and Subject 23 / Trial 17 (Actor B)
- Official description: “rush up, arm wrestle”
- Converted FBX distribution: https://huggingface.co/datasets/gbionics/cmu-fbx
- Original CMU terms: motions may be copied, modified and redistributed; inclusion in commercially sold products is permitted; the motion data itself must not be resold, including in converted form.
- Required acknowledgement requested by CMU for published results: “The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.”
- The two files are the matched A/B recordings from the same trial. Both clips are 6.900 seconds long and carry hip-position tracks; key counts differ, so runtime playback uses a shared elapsed-time clock rather than assuming identical keyframe counts.
- This is an actual paired human interaction capture, but it is arm wrestling — not an MMA takedown, submission, or ground-grappling capture.
- The files are included as game motion assets, not offered for resale as a standalone animation pack.
