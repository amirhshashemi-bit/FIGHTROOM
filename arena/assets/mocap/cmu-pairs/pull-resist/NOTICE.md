# CMU paired motion capture — pull / resist interaction

- Original source: Carnegie Mellon University Graphics Lab Motion Capture Database.
- Official motion index: https://mocap.cs.cmu.edu/search.php?maincat=1&subcat=1
- Actor A: Subject 18, Trial 3 — “A pulls B; B resists”.
- Actor B: Subject 19, Trial 3 — matching “A pulls B; B resists” recording.
- Converted FBX distribution: https://huggingface.co/datasets/gbionics/cmu-fbx
- Both clips are 4.900 seconds long and include root-position tracks. Runtime playback uses a common elapsed-time clock; actor key counts differ.
- CMU terms permit copying, modifying and redistributing the motion data and inclusion in commercial products; the motion data itself must not be resold, including in converted form.
- Required acknowledgement requested by CMU for published results: “The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.”
- This is a real paired human interaction capture of pulling and resisting. It is not a dedicated MMA double-leg takedown, pummelling, BJJ guard transition or submission.
