# ACCAD motion capture attribution
Motion data: Open Motion Project by ACCAD / The Ohio State University.
License: Creative Commons Attribution 3.0 Unported (CC BY 3.0).
Source: https://accad.ohio-state.edu/research/motion-lab/mocap-system-and-data
Original archive: https://accad.ohio-state.edu/sites/accad.osu.edu/files/Male2_bvh.zip
The source inventory identifies the selected motions as real motion-capture takes, including boxing punches, kicks, blocks, dodges, stance, lie-down and crawl motions. These are single-performer motions, not paired wrestling/submission capture.
FIGHTROOM stores selected source BVH files unmodified. File checksums and frame metadata are in manifest.json.
