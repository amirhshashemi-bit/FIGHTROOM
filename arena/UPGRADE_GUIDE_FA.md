# راهنمای نسخه‌بندی و ارتقای FIGHTROOM ARENA

## وضعیت فعلی
- نسخه: 0.9.1-prealpha
- شاخه توسعه: `arena-combat-foundation`
- مسیر یگانه بازی: `arena/`
- اطلاعات نسخه و سازگاری: `build-info.json`
- داده‌های مبارز سفارشی در مرورگر: `fightroom.arena.custom-fighter.v1`
- نسخه ساختار ذخیره فعلی: `2`

## قواعد ارتقا
1. تغییرات بازی فقط در شاخه توسعه انجام شود؛ `main` و نسخه منتشرشده تا زمان تأیید نهایی دست‌نخورده بمانند.
2. هر انتشار جدید باید مقدار `version` در `build-info.json` و `arena/package.json` را هماهنگ افزایش دهد.
3. تغییر ساختار ذخیره بازیکن باید با افزایش `CREATOR_SCHEMA_VERSION` و مهاجرت داده‌های نسخه قبلی انجام شود. داده‌های بازیکن نباید با تغییر نسخه پاک شوند.
4. مدل‌ها و موشن‌ها باید نسخه، منبع، مجوز و checksum داشته باشند؛ هیچ فایل موشن بدون بررسی مجوز وارد انتشار نشود.
5. قبل از انتشار، آزمون‌های Node، آزمون مرورگر دسکتاپ، آزمون نمای لمسی Android و سپس تست گوشی واقعی اجرا شوند.
6. انتشار عمومی فقط از مسیر Pull Request تأییدشده به `main` انجام شود؛ GitHub Pages از `main` منتشر می‌کند.
7. برای بازگشت نسخه، commit یا release قبلی بازیابی شود؛ داده‌های ذخیره بازیکن مستقل از فایل‌های بازی نگه داشته شوند.

## جلوگیری از مسیرهای موازی
- `arena/` تنها محل سورس بازی است.
- صفحه اصلی مخزن و پوشه `arena/` دو بخش متفاوت محصول هستند، نه دو کپی از بازی.
- فایل‌های workflow زیر `.github/workflows/` صرفاً آزمون/انتشار هستند؛ نباید runner محلی دوم یا کپی دیگری از بازی ایجاد شود.
- نسخه‌های پشتیبان باید خارج از مسیر اجرایی و با تاریخ/نسخه مشخص نگهداری شوند؛ فایل‌های پشتیبان نباید به‌عنوان نسخه قابل اجرا استفاده شوند.

## محدودیت‌های شناخته‌شده
این نسخه هنوز پیش‌انتشار است. موشن‌کپچر دونفره CMU فقط کشتی دست و کشیدن/مقاومت را پوشش می‌دهد، نه فنون کامل MMA. سیستم پرداخت/اشتراک واقعی، APK، تست فیزیکی Android و بهینه‌سازی نهایی روی لپ‌تاپ هنوز تأیید نشده‌اند.
